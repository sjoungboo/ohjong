# 기회 게이지

미국 상장 1,184종목을 20년치 기록과 대조해 단기(3개월)·장기(12개월) 점수를 보여주는 정적 페이지입니다.

## 구성

- `index.html` — 데이터가 내장된 단일 파일. 이것 하나면 됩니다.

## 갱신

점수는 생성 시점에 고정됩니다. 갱신하려면 `index.html`을 새로 만들어 덮어쓰면 됩니다.

## 데이터 출처

- 가격 · 거래량 : Yahoo Finance (상업적 재배포 금지 — 유료화 시 벤더 교체 필요)
- 재무제표 : SEC EDGAR XBRL (공시 제출일 기준)
- 거시지표 : FRED, 선물·ETF 시세

## 주의

투자 권유가 아닙니다. 과거 통계이며, 상장폐지된 기업이 데이터에 포함되지 않아
모든 수치가 실제보다 낙관적입니다.
